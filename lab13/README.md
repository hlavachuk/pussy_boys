# Лабораторна робота №13

Варіант 7 — банк «Прут-Кредит». Java 17+, консольне моделювання без UI, бази даних, мережі та сторонніх бібліотек.

## Запуск

```sh
cd lab13
./run.sh
./test.sh
```

У IntelliJ IDEA: відкрити цю теку, обрати JDK 17+, позначити `src` як Sources Root та запустити `Main`. Лабораторні компілюються окремо, бо кожна має власний `Main`. Скрипти працюють у POSIX shell; Windows: IntelliJ або Git Bash.

Кожний `Main.taskN()` відтворює відповідний сценарій. Журнал має формат `[умовний час] [джерело] подія`; час — послідовний лічильник. `common.Logger` — єдиний вивід у консоль.

## Відповідність завданням

| Завдання | Шаблон | Сценарій |
| --- | --- | --- |
| 1. Погодження кредиту | Chain of Responsibility | `Main.task1()`; пакет `Task1` |
| 2. Відкладені платежі | Command | `Main.task2()`; пакет `Task2` |

Окремі UML для кожного рішення наведені нижче. Пояснення вибору шаблонів: [підготовка до захисту](docs/defense.md). Вимоги: [ситуації варіанта](docs/requirements.md).

## UML

Типи згруповані у тематичні класи-контейнери: наприклад, `Task1.LoanApproval.…`. На схемах використані прості імена вкладених типів. Позначено ролі, доступи, ключові поля/методи та кратності; наслідувані члени повторно не дублюються. Record-поля приватні final; публічні accessor-методи генеруються Java.

- [task1_chain](docs/diagrams/task1_chain.svg) · [PlantUML](docs/diagrams/task1_chain.puml)
- [task2_command](docs/diagrams/task2_command.svg) · [PlantUML](docs/diagrams/task2_command.puml)

## Межі моделі

Операційна дата задається явно, час рухається лише вперед. Прострочена команда виконується в день обробки черги; сторно дозволено в цей самий день. Повторення задаються скінченним числом окремих команд.

## Командне рев’ю

Технічні перевірки виконані. Обов’язкове взаємне рецензування двома студентами залишається виконати команді: [чекліст і протокол](docs/review.md). Авторство, підписи та вигадані відгуки не підставлено.
