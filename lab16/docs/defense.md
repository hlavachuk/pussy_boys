# Підготовка до захисту №16

Обидва члени команди мають пояснювати всю лабораторну незалежно від розподілу завдань.

## 1. Обхід операцій клієнта: Iterator

`Archive` приховує рахунки → місяці → архівні блоки. `LatestIterator`, `YearIterator`, `MonitoringIterator` мають власні курсори та незмінні знімки. Показано 10 останніх операцій, хронологічний 2026 рік і чергування двох незалежних обходів. Фінмоніторинг використовує модуль суми строго понад 400000 грн.

Покажіть `Main.task1()`, відповідний файл у `src/Task1/`, журнал та UML. Поясніть ролі учасників і точку розширення.

## 2. Відкат операційного дня: Memento

`Ledger` створює приватний static `Snapshot` з незмінною копією залишків. `History` бачить лише порожній інтерфейс `Checkpoint`, не може читати або міняти вміст. UA1/UA2: 10000/20000 → 11000/19500 → помилкові 2000/118500 → відновлення другої та першої точок. Чужі та підроблені знімки відхиляються.

Покажіть `Main.task2()`, відповідний файл у `src/Task2/`, журнал та UML. Поясніть ролі учасників і точку розширення.

## 3. Операції над банківськими продуктами: Visitor

`accept()` виконує подвійну диспетчеризацію до перевантаженого `visit()`. `Reserves`, `Profitability` та новий `ClientReport` мають власну логіку для депозиту, кредиту, картки та інвестицій. Кожна операція обходить портфель один раз. Навчальні підсумки: резерви 13600.00, прибутковість 28700.00.
