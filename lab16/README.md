# Лабораторна робота №16

Варіант 7 — банк «Прут-Кредит». Java 17+, консольне моделювання без UI, бази даних, мережі та сторонніх бібліотек.

## Запуск

```sh
cd lab16
./run.sh
./test.sh
```

У IntelliJ IDEA: відкрити цю теку, обрати JDK 17+, позначити `src` як Sources Root та запустити `Main`. Лабораторні компілюються окремо, бо кожна має власний `Main`. Скрипти працюють у POSIX shell; Windows: IntelliJ або Git Bash.

Кожний `Main.taskN()` відтворює відповідний сценарій. Журнал має формат `[умовний час] [джерело] подія`; час — послідовний лічильник. `common.Logger` — єдиний вивід у консоль.

## Відповідність завданням

| Завдання | Шаблон | Сценарій |

Окремі UML для кожного рішення наведені нижче. Пояснення вибору шаблонів: [підготовка до захисту](docs/defense.md). Вимоги: [ситуації варіанта](docs/requirements.md).

## UML

Типи згруповані у тематичні класи-контейнери: наприклад, `Task1.ClientOperations.…`. На схемах використані прості імена вкладених типів. Позначено ролі, доступи, ключові поля/методи та кратності; наслідувані члени повторно не дублюються. Record-поля приватні final; публічні accessor-методи генеруються Java.

## Межі моделі

Усі фінансові ставки — явні навчальні припущення, не актуальні тарифи, податки чи нормативи НБУ. Гроші обчислюються через `BigDecimal`, округлення до 2 знаків HALF_UP.
Резерви: депозит 2%, кредит 5%, картка 1%, інвестиції 3%. Річна прибутковість: депозит −12% (витрата), кредит +20%, картка +2%, інвестиції +1%. Ставки не задані PDF, тому обрані й задокументовані лише для демонстрації Visitor. Iterator обходить знімок, не транслює подальші зміни архіву.
