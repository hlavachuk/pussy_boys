# Підготовка до захисту №14

Обидва члени команди мають пояснювати всю лабораторну незалежно від розподілу завдань.

## 1. Видача кредиту: Mediator

Учасники знають лише `Mediator` і повідомляють події. `LoanCoordinator` чекає всіх позитивних перевірок, передає юристам, після підпису дозволяє видачу касиру. Відмова безпеки зупиняє процес. `CollateralAppraiser` підключається через `addCheck()` без змін існуючих учасників.

Покажіть `Main.task1()`, відповідний файл у `src/Task1/`, журнал та UML. Поясніть ролі учасників і точку розширення.

## 2. Зміна курсу валют: Observer

`RateService` зберігає інтерфейси `Observer`; конкретні отримувачі реагують самі. При 41.50 клієнт з порогом 41.00 мовчить, при 40.90 отримує повідомлення, після відписки при 40.80 мовчить; табло, банкінг і конвертація продовжують отримувати курс. `MobileApp` підключається без змін служби.

Покажіть `Main.task2()`, відповідний файл у `src/Task2/`, журнал та UML. Поясніть ролі учасників і точку розширення.
