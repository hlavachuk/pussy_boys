# Підготовка до захисту №12

Обидва члени команди мають пояснювати всю лабораторну незалежно від розподілу завдань.

## 1. Структура банку: Composite

`Unit` уніфікує касу й підрозділ, `Department` рекурсивно підсумовує дітей. Два регіони, вкладене міні-відділення. Загалом 200000 грн і 43 операції; західний регіон 120000 грн і 28 операцій. Один `report(Unit)` для будь-якого вузла.

Покажіть `Main.task1()`, відповідний файл у `src/Task1/`, журнал та UML. Поясніть ролі учасників і точку розширення.

## 2. Платіжні документи: Bridge

`Document` визначає зміст, `Delivery` — спосіб надання. Усі 3 види сумісні з усіма 4 способами. Та сама квитанція перемикається з друку на PDF; довідка з підпису на Дію. `Diia` додає один клас.

Покажіть `Main.task2()`, відповідний файл у `src/Task2/`, журнал та UML. Поясніть ролі учасників і точку розширення.

## 3. Історія операцій: Flyweight

Незмінний `Merchant` містить спільні назву, логотип, категорію, MCC та адресу. `MerchantFactory` інтернує за ID й не створює об’єкт при повторному зверненні. `Operation` містить суму, дату, рахунок та посилання. 50000 операцій використовують рівно 20 торговців; `==` підтверджує спільний об’єкт.
